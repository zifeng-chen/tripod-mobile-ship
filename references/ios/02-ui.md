# iOS · UI 规范

## 单位与颜色

pt / 字号用 `Font.system(size:)`，颜色走 `Color("token")`（Asset Catalog，含 Any/Dark 两套）。

```swift
enum T { static let R_CARD: CGFloat = 16; static let R_PILL: CGFloat = 999 }
```

禁止在 View 里写 `.foregroundColor(.black)` 这类硬编码，深色模式会翻车。

## 布局

- 一屏一个 `ScrollView`，卡片用 `VStack(spacing: 12~16)`
- 卡片：`RoundedRectangle(cornerRadius: 16)` 背景 + 1px 描边（`stroke`），**不要 `.shadow`**
- 安全区：`safeAreaInset(edge: .bottom)` 给底部固定栏留位置，不要用负数 padding 硬顶
- 二级页 `NavigationStack` + `navigationBarTitleDisplayMode(.inline)`

## 按钮

```swift
Button("保存") { … }
  .frame(maxWidth: .infinity, minHeight: 44)
  .background(Pal.primary)
  .foregroundStyle(.white)
  .clipShape(Capsule())
```

**坑：`.disabled(true)` 会把整块（含白字）调暗成灰**。要保持亮色时不要用它：

```swift
.allowsHitTesting(!busy)        // 仍然可点但由逻辑拦住
.opacity(busy ? 0.55 : 1)
```

或者用自定义 `ButtonStyle` 自己控制 `isPressed` 与禁用外观。

行内操作胶囊：`minWidth: 78, height: 36, clipShape(Capsule())`。

## 图标

用 SF Symbols 或自带 PDF 矢量：
`Image("ic_x").renderingMode(.template).foregroundStyle(Pal.primary)`。
不要用 `Path` 手绘多条线（多段 M 容易只画出第一段）。

## 弹层

`.sheet` + `.presentationDetents([.medium, .large])`。
关闭键：30×30 圆角 8 的方块，**别做正圆**。
弹层内按钮放 `safeAreaInset`，别跟内容一起滚。

## 交互细节

- 长按复制：`.textSelection(.enabled)`
- 大列表用 `LazyVStack`，别一次性渲染
- 返回手势：保留系统边缘手势，别自己拦截
- 触觉反馈适度：`UIImpactFeedbackGenerator(style: .light)`

## 深浅色

`Color("token")` 一套名称两套值；切换后 SwiftUI 自动重绘，自定义 `Canvas`/`UIViewRepresentable` 要手动刷新。

## 自查

- 逐页切深色看一遍（模拟器 `Cmd+Shift+A`）
- 用 Accessibility Inspector 量对比度与热区
