# 设计令牌与组件形状（三端共用一套数值）

## 色板

| 令牌 | 值 | 备注 |
|---|---|---|
| `primary` | `#00805E` | 白字压上去 4.95:1，刚过 AA，不要再调浅 |
| `accent_soft` | 主色 7% 叠白 | 9% 时主色文字只有 4.48，会踩线 |
| `danger` | `#C0392B` | 只给破坏性操作 |
| `text_primary` | `#111111` | |
| `text_secondary` | `#5F6A64` | 白底 5.7:1 |
| `text_tertiary` | `#67706B` | 白底 5.0:1，是下限 |
| `surface` / `surface_hi` / `surface_sunken` | 白 / `#F2F4F3` / `#EEF2F0` | 三级层次够用 |

深色模式每个令牌都要有对应值；切换时自绘组件必须重取颜色（鸿蒙要清缓存）。

## 尺寸阶梯

- 圆角：`XS 8 · SM 12 · CARD 16 · LG 20 · PILL 999`
- 间距：`4 / 8 / 12 / 16 / 20 / 24`
- 卡片内边距 14~16；卡片之间 12~16
- 字号：`11.5 / 13 / 15 / 17 / 20 / 28`（Android 用 sp、iOS 用 pt、鸿蒙用 fp，数值相同）

## 组件形状约定

| 组件 | 规矩 |
|---|---|
| 卡片 | 背景 `surface`，圆角 `CARD`，1px 描边分层；**不要投影**（投影只给浮层） |
| 主/次按钮 | 胶囊 `PILL`，高 44~48，最小宽 88 |
| 行内操作胶囊 | 胶囊，高 36~44，**最小宽 78**（44×44 会变成正圆） |
| 弹层关闭键 | 30×30，圆角 `XS` 方块，不要正圆 |
| 图标 | 24 格设计稿、描边 2、圆头；导出留 26 视口 |
| 空态 | 一句话说清"为什么空 + 怎么办"，别只放图标 |

## 对比度硬线

- 正文 ≥ 4.5:1；大字（≥24dp 或 ≥19dp 加粗）≥ 3.0:1
- hero 上的次要文字：白 85% 只有 4.02，要到 **95%**（4.63）
- 透明画布上的图标会被审核当文本取色（前景=背景 → 1.03），**不要自绘**

## 热区

iOS 44pt / Android 48dp / 鸿蒙 44vp。
量的是**控件自身矩形**，不能靠外层容器撑；`dumpLayout` 里 `clickable=true` 的节点逐个核。

## 命名与代码组织

- 令牌常量类：`T`（尺寸/字号）、`Pal`（颜色，带 `$r()` 资源 + 兜底字面量）
- 组件：`Card` / `CardHeader` / `Sheet` / `GlyphIcon` 这类单一职责小件，页面里只组合不重写
- 页面按「一层一个文件」拆分，二级页单独文件，别塞进主页面
