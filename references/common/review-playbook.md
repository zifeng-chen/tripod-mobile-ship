# 过审手册（三端共通）

审核只量三件事：**看得清**（对比度/图标）、**说得清**（隐私/主体/备案）、**跑得通**（能不能测）。

## 提审前自查

| 项 | 要求 | 怎么验 |
|---|---|---|
| 主体一致 | 应用内署名/公司名 **必须**与开发者后台实名一致 | 全局搜署名文案 |
| 隐私政策 | 应用内可见；首启不勾选就走不下去 | 关掉协议开关试一次 |
| 权限 | 只声明用得到的；普通权限不弹框 | Manifest / Info.plist / module.json5 |
| 数据收集 | 无第三方统计/广告 SDK；请求只发用户自己填的地址 | 全局搜 SDK 名 |
| 演示可用 | 无设备/无账号也能看到界面 | 空配置启动试一遍 |
| 对比度 | 正文 ≥4.5:1 | `scripts/contrast_audit.py` |
| 图标 | 不用自绘 Canvas；小尺寸不糊 | 看控件类型 |
| 热区 | 见设计令牌文档 | dumpLayout 挑 <44 的节点 |
| 适配 | 声明的设备类型都要能开（手机/平板/2in1） | 至少跑一次宽屏 |
| 深浅色 | 两套色板逐页看 | 切主题后走一遍 |
| 崩溃 | 冷启动到末页无 crash | faultlogger / Crashlytics 为空 |
| 包签名 | release 证书 + 正确包名版本 | 验签脚本 |

## 五类高频驳回

**① 对比度不足（"控件类型 Text，对比度 1.03"）**
真凶通常是透明画布上的图标被当文本取色。改：图标落成矢量资源；顺带查 hero 次要文字。

**② 图标锯齿（"Canvas 锯齿 94.67 > 90"）**
自绘细线在高分屏边缘不干净。改：矢量资源 + 系统渲染。

**③ 主体信息不一致**
应用内写花名/英文名 ≠ 后台实名。一律用实名，并同步隐私政策、关于页、版权声明。

**④ APP 核准（备案）未通过**
单机/无服务器应用：在「分发 → 版本信息 → 备案信息」选 **「您的APP为单机APP」**；
有大陆服务器需先拿备案号。三处必须一致：主体、应用名、包名。

**⑤ 需要演示录屏（"需要连设备，无法测试"）**
要求：从启动开始、完整走一遍核心功能、在真机（或官方模拟器）上录制。

录屏脚本建议（90~180 秒）：

1. 冷启动 → 启动图 → 登录/首页
2. 显式展示「没有设备也能进」的入口并点进去
3. 每个一级页签停 4~6 秒，**上下滑动**把卡片露全
4. 至少进 2~3 个二级页、1 个三级页（列表→详情）
5. 有弹层的页面点开再关掉
6. 回首页收尾

## 材料清单

| 字段 | 注意 |
|---|---|
| 应用名称 | ≤15 汉字/30 字符；无价格词、无"官方"暗示 |
| 一句话简介 | ≤30 字，说清给谁解决什么 |
| 应用介绍 | 不夸大、不堆关键词、不蹭他人商标 |
| 版本说明 | 与实际改动一致，别复用上一版 |
| 截图 | 覆盖主要页面；有平板/2in1 补对应截图 |
| 测试账号 | **别留空**；用演示模式要写清进入路径 |
| 隐私政策 URL | 能打开的 https，内容与应用内一致 |

## 被驳回之后

1. 先分清是**代码问题**还是**材料问题**（材料问题改代码没用）
2. 代码：改 → 升版本 → 出包 → 撤审 → 传包 → 补资料 → 提审
3. 材料：撤审（或直接改，看状态）→ 改资料 → 重提
4. 每次重提都**复查隐私协议绑定**（网页改过版本信息会被清空）
