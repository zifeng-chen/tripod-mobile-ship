# Android · UI 规范

## 单位

`dp` 尺寸、`sp` 字号、颜色走 `res/values/colors.xml`（深浅两套 `values-night`）。
Java 里禁止 `Color.parseColor("#…")` 和硬编码 `12dp`。

## 布局

- 一屏一个根 `ScrollView`（或 `NestedScrollView`），卡片纵向排列，间距 12~16dp
- 卡片：`MaterialCardView` + `cardCornerRadius = 16dp` + 1dp 描边，**`cardElevation = 0`**
- **`CardView` 的左右内边距默认是 0**，内容会贴边——必须在内容容器上补 14~16dp
- 列表用 `RecyclerView` + `ListAdapter`，`notifyItemChanged` 只刷变化的项
- 二级页用独立 Activity，标题栏自己画（左返回 + 居中标题），别依赖 ActionBar

## 按钮

```xml
<com.google.android.material.button.MaterialButton
    android:layout_height="44dp"
    android:minWidth="88dp"
    app:cornerRadius="22dp"        <!-- = 高度/2，胶囊 -->
    android:insetTop="0dp" android:insetBottom="0dp" />
```

- 行内操作胶囊：高 36dp、最小宽 78dp、`cornerRadius = 18dp`
- 危险操作：`danger` 底色 + 白字，只出现在确认弹层里
- **不要**给按钮 `cornerRadius` 设成宽高的一半以下再配正方形（那是圆不是胶囊）

## 图标

- 用 `VectorDrawable`，`android:tint="?attr/colorPrimary"` 着色
- 24dp 网格、2dp 描边、圆头端点；导出留 26 视口余量
- 行尾箭头（`>`）用 drawable，不要用字符

## 弹层

`BottomSheetDialog`：圆角 20dp、顶部拖拽条 4×32dp、关闭键 30×30dp 圆角 8dp 方块。
弹层里的按钮固定在内容之外（`ScrollView` 外），跟随键盘时要 `adjustResize`。

## 无障碍与热区

- 所有可点元素 `minHeight = 48dp`（Material 标准），行内小胶囊至少 44dp
- `contentDescription` 必填：图标按钮、开关、列表项的状态
- 文字对比度见 `common/design-tokens.md`，正文 4.5:1

## 深浅色

`values-night/colors.xml` 一套对应值；切换后 `recreate()` 让已渲染页面重取色。
自绘 View 要在 `onConfigurationChanged` 里刷新画笔颜色。
