# HarmonyOS · UI 规范（ArkTS）

## 状态管理：只用 V2

`@Local`（组件内状态）/ `@Param`（入参）/ `@Event`（回调）/ `@Monitor`（监听）。
**不要用 V1 的 `@State/@Prop/@Watch`**，混用会不刷新。

跨页状态放单例（如 `core/UIState.ets` 的 `UI`）：当前页签、安全区、返回计数都在这里。

## 设计令牌

`ui/Theme.ets`：`T`（尺寸/字号/圆角）、`Pal`（颜色）。
`Pal.xxx()` 走 `$r('app.color.xxx')` 并带宽色兜底，页面里禁止 `'#00805E'` 这类字面量。

```ts
T.R_XS=8  R_SM=12  R_CARD=16  R_LG=20  R_PILL=999
T.F_TINY=11.5  F_SUB=13  F_BODY=15  F_H2=17  F_H1=20
```

## 布局

- 一级页 `Column` + `Scroll`，卡片 `Card()`（`Comp.ets`）统一圆角/描边/内边距
- **`CardHeader` 自带 `width('100%')`**，和它并排的 `Text` 会被挤掉 → 外层包 `Row` 或给 Text `layoutWeight(1)`
- 二级页：`@Local sub` + `Shell.enter/leave` + `@Monitor('ui.backTick')`，返回栏放在 `Scroll` 外面固定
- 宽屏（≥600vp）切侧栏：`SideNav` + `DuoLayout`，不要写死两栏

## 组件

| 件 | 规矩 |
|---|---|
| 按钮 | `Button` + `R_PILL`，高 44，行内胶囊最小宽 78 |
| 图标 | `Image($r('app.media.ic_x'))` + `.colorFilter(drawing.CreateBlendMode(Color.Transparent, drawing.BlendMode.SRC_IN))` |
| 弹层 | `bindSheet`，**一个组件只能挂一个**，多个会只有最后一个生效 |
| 分段控件 | 格子高 36 + 轨道 padding 4 = 44 |

图标必须走 `GlyphIcon`（`Image`），**不要用 Canvas/`Path` 自绘**：
审核按控件类型量对比度（透明画布取到同色 → 1.03）和锯齿（小尺寸细线 > 90）。

## 无障碍

- 可点元素 `.accessibilityText('…')`，图标按钮必填
- 热区：控件自身矩形 ≥44vp；行内小胶囊靠 `constraintSize({minHeight:44,minWidth:78})`
- 长地址：点开弹层 + `.copyOption(CopyOptions.LocalDevice)`，整段换行、可选中

## 深浅色

`resources/base` + `resources/dark` 两套 `color.json`，token 名一一对应。
自绘组件在主题切换时要清缓存重取色（`Pal.reset()` 之类）。

## 性能

- `LazyForEach` 用户列表，`ForEach` 的 key 必须含会变的字段
- 轮询用 `setInterval` 但页面 `onPageHide` 要清掉，别在后台空转
- 大图用 `Image` 的 `objectFit(ImageFit.Contain)`，别拉满分辨率
